# IMDB Data Cleaning with Pandas

This project demonstrates a complete data cleaning workflow using Pandas.

## Tasks performed

- Removed invalid values
- Converted numeric columns
- Cleaned text columns
- Handled missing values
- Handle blanks and extra spaces
- Fixed data types
- Exported a cleaned dataset

## Library

- Pandas
